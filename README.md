## Email Flows (Klaviyo)

1. **Welcome Series** (3 emails)
   - Welcome + discount code
   - Brand story + best sellers
   - Social proof + reviews

2. **Abandoned Cart** (3 emails)
   - Reminder (1 hour)
   - Urgency (24 hours)
   - Final chance + incentive (48 hours)

3. **Post-Purchase** (4 emails)
   - Order confirmation
   - Shipping notification
   - Delivery follow-up + care tips
   - Review request

4. **Win-Back** (2 emails)
   - We miss you (30 days)
   - Special offer (60 days)

5. **Browse Abandonment** (2 emails)
   - Product reminder
   - Similar products
